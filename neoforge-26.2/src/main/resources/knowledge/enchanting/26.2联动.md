# 附魔辅助联动

对应 modid：`enchdesc`, `enchantmentinsights`, `easymagic`, `taxfreelevels`

## AI 使用方式

- 附魔说明：提示 Enchantment Descriptions 会显示附魔效果。
- 附魔台预览：提示 Enchantment Insights 可辅助判断附魔结果。
- 附魔台操作：Easy Magic 提供便捷体验。
- 经验成本：Tax Free Levels 降低高等级经验损耗压力。
- 生成附魔物品指令时，26.2 必须优先使用 item components：

```mcfunction
/give @s minecraft:diamond_sword[minecraft:enchantments={levels:{"minecraft:sharpness":5}}] 1
```

## 边界

不要输出旧式 `{Enchantments:[...]}` NBT 作为 26.2 首选格式。
