# 26.2 联动清单

本清单只适用于 MC 26.2 / NeoForge 26.2.0.7-beta 的 `xxsx_mc_smart_core`。

## 使用方式

- `[QUERY]integrations[/QUERY]`：列出已检测到的可联动项。
- `[QUERY]integrations <关键词>[/QUERY]`：按 modid、主题或名称过滤。
- `[QUERY]mod <modid>[/QUERY]`：检查某个 mod 是否安装，并提示对应知识主题。
- `[QUERY]commands <分类/modid/动作>[/QUERY]`：查询内置联动动作目录和可执行模板，支持 `commands add 饰品栏`、`commands nihility`、`commands earth_human`、`commands slots` 这类便携分类查询。
- `[QUERY]curios <动作> [槽位] [数量][/QUERY]`：查询 Curios 饰品槽位命令模板，例如 `curios add ring`。
- `[QUERY]doc <主题或modid>[/QUERY]`：读取联动文档。
- `[QUERY]recipe <物品ID>[/QUERY]`：查服务端配方索引。
- `[QUERY]jei <物品ID>[/QUERY]`：提示 JEI 可用性并列出服务端配方。

## 原则

- 这些联动都是可选检测和知识增强，不新增编译硬依赖。
- 如果某个 mod 未安装，AI 仍可读取文档并给出安装/使用建议。
- 回答具体配方时优先用 `[QUERY]recipe` 或 `[QUERY]jei` 查当前运行时数据。
- 回答具体可执行操作时优先用 `[QUERY]commands` 或对应快捷查询（如 `[QUERY]commands add 饰品栏[/QUERY]`、`[QUERY]curios add ring[/QUERY]`）拿命令模板，再用 `[CMD]` 执行。工具结果会以 `[TOOL_RESULT]` 回灌，模型应自行判断是否继续。
- 会改变玩家、世界或服务器状态的 `[CMD]` 不会立即执行，而是等待玩家输入 `/ai y` 或 `/ai confirm`；玩家可用 `/ai n`、`/ai cancel` 或 `/ai stop` 放弃。模型收到 `confirmation_required=true` 后必须等待，不得重复同一条命令。
