# JEI / JustEnoughProfessions 联动

对应 modid：`jei`, `justenoughprofessions`

## AI 使用方式

- 用 `[QUERY]mod jei[/QUERY]` 检查 JEI 是否安装。
- 用 `[QUERY]jei <物品ID>[/QUERY]` 提醒玩家客户端可按 R 查合成、按 U 查用途，并用服务端配方索引列出可见配方。
- 用 `[QUERY]recipe <物品ID>[/QUERY]` 在不依赖 JEI API 的情况下查询服务端配方结果。
- 遇到职业/工作方块问题时，先查询 `justenoughprofessions` 是否安装，再建议玩家在 JEI 职业界面确认工作方块。

## 边界

本联动不直接调用 JEI API，不把 JEI 作为硬依赖；机器配方、隐藏配方、客户端插件配方可能无法被服务端配方索引完整列出。
