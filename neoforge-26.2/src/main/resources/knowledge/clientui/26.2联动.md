# 客户端 UI / 操作辅助联动

对应 modid：`legendarytooltips`, `controlling`, `mousetweaks`, `sodium`, `sodium_extra`, `drippyloadingscreen`, `fancymenu`

## AI 使用方式

- 物品辨识：Legendary Tooltips 改善稀有物品提示框可读性。
- 键位冲突：Controlling 用来查找和处理按键冲突。
- 库存操作：Mouse Tweaks 改善批量移动物品体验。
- 性能/显示：Sodium 和 Sodium Extra 影响客户端渲染性能与显示设置。
- 主菜单/加载界面：FancyMenu 和 Drippy Loading Screen 负责客户端界面美化。

## 边界

这些多为客户端体验层 mod，AI 只做使用建议和故障排查引导，不直接调用其 API。
