# Curios 联动

对应 modid：`curios`

## AI 使用方式

- 当玩家要求添加/设置/减少 Curios 饰品槽位时，不要只读文档，先查内置指令库。
- 查询 Curios 是否安装：`[QUERY]mod curios[/QUERY]`。
- 查询可执行模板：`[QUERY]commands add 饰品栏[/QUERY]`、`[QUERY]commands add ring[/QUERY]`、`[QUERY]commands slots[/QUERY]`，或更直接的 `[QUERY]curios add ring[/QUERY]`。
- 如果玩家只说“加一个饰品栏位”，默认使用通用槽位 `curio`：`/curios add curio @s 1`。
- 如果玩家说戒指、护符、项链等，按槽位别名映射：戒指=`ring`，护符=`charm`，项链=`necklace`。
- 查询/执行后系统会把 `[TOOL_RESULT]` 回灌给模型并自动让模型判断下一步；查到会修改槽位的 `[CMD]` 模板后，系统会等待玩家 `/ai y` 或 `/ai confirm`，模型不得重复同一条命令。

## 常用命令模板

这些模板来自当前 26.2 实例的 Curios `curios-neoforge-15.0.0-beta.1+26.2.jar` 命令注册：

```mcfunction
/curios list
/curios add <slot> <player> [amount]
/curios set <slot> <player> [amount]
/curios remove <slot> <player> [amount]
/curios clear <player> [slot]
/curios drop <player> [slot]
/curios reset <player>
/curios replace <slot> <index> <player> with <item> [count]
```

常用示例：

```mcfunction
/curios add curio @s 1
/curios add ring @s 1
/curios set ring @s 2
/curios remove ring @s 1
/curios clear @s ring
```

内置槽位：`back`、`belt`、`body`、`bracelet`、`charm`、`curio`、`feet`、`hands`、`head`、`necklace`、`ring`。

## 边界

`xxsx_mc_smart_core` 不把 Curios 作为编译硬依赖；这里提供运行时检测、指令模板查询和可选执行辅助。`/curios list` 属于只读操作；添加、设置、减少、清空、掉落、重置和替换槽位会先请求玩家确认。真正槽位系统仍由已安装的 Curios mod 提供。
